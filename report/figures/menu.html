RANDOM MAZE                                   
                                                                                
            1   One player vs the computer                                      
                Race an A* bot through the same maze. You: arrows or W A S D.   
                The bot only sees 2 / 3 / 4 squares around it (by level) and    
                replans every time it finds a wall. You see its whole maze.     
                                                                                
            2   Two players over the network (PvP)                              
                Each player runs MAZE on their own PC or phone and presses 2,   
                then types the server IP and port; the server pairs them up.    
                Start the server on one PC in the same Wi-Fi:  maze <port>      
                Same maze for both. First to the exit wins (30/45/60 s).        
                                                                                
            3   Cognitive study (human learns first)                            
                You run one maze again and again until you walk the optimal     
                path. Then the bot does the same on that maze, keeping what it  
                has seen, and both learning curves are compared. 3 stages.      
                                                                                
                                                                                
            ESC Exit to DOS                                                     
                                                                                
                                 Press 1, 2 or 3
